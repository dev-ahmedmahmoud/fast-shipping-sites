# fast-shipping-sites

Syncology's engine for bilingual (Arabic/English) client websites: a set of reusable design systems, a per-client content pack, and a sample gallery so each client can pick a look before launch.

Status: discovery. The engine is not built yet.

## Layout

- `onboarding/intake.html`: the intake questionnaire, published as a Claude artifact. Part A (platform) is answered once; Part B is one per client.
- `clients/<slug>/`: per-client research and, later, content.
