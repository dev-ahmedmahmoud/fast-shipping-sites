# Fonts

Arabic and Latin subsets of two Google Fonts families, self-hosted by Orbit (see `../type.ts`). Both are under the SIL Open Font License 1.1 (licences in this folder), which allows bundling them with a website.

| File | Family | Designer |
| --- | --- | --- |
| `alexandria-arabic.woff2`, `alexandria-latin.woff2` | Alexandria (variable, 500–800) | The Alexandria Project Authors |
| `readex-pro-arabic.woff2`, `readex-pro-latin.woff2` | Readex Pro (variable, 300–600) | The Readex Pro Project Authors |

Downloaded from fonts.googleapis.com on 2026-11-08. To refresh them, request `Alexandria:wght@500..800` and `Readex+Pro:wght@300..600` from the Google Fonts CSS API with a modern browser user agent and save the `arabic` and `latin` woff2 subsets under these names.
