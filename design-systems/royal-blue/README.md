# Royal Blue (palette only): now navy and gold

November 2026: the client's agent sent a new design, so the colours are now its deep navy `#15396A`, metallic gold `#D2A24C` (light `#E1CB92`, deep `#BD8F33`) and a warm cream background `#FAF6EF`. The folder keeps its old name because the live build selects the palette by it (`DS_PALETTE=royal-blue`). The original poster colours are below for the record.

Colours sampled from the Tanta Sports Club list's 2026 campaign poster: royal blue `#23449A` with the poster's deep navy (`#242563`, `#293179`) reached through layouts that mix accent with ink, a sky-blue glow (`#70A8DB`), white names (`#F7F6FA`) and campaign gold-yellow (`#EDD427`, ties and crest `#FBE107`). Ink is the near-black navy of the members' suits.

This folder only provides `palette.ts`. Use it as the `palette` part of a sample, for example `{ "palette": "royal-blue", "type": "station", "layout": "station", "motion": "station" }`.
