# Fonts

Subsets of three Google Fonts families, self-hosted by Comic Class (see `../type.ts`). All three are under the SIL Open Font License 1.1 (https://openfontlicense.org), which allows bundling them with a website.

| File | Family | Designer |
| --- | --- | --- |
| `baloo-bhaijaan-2-arabic.woff2`, `baloo-bhaijaan-2-latin.woff2` | Baloo Bhaijaan 2 (variable, 400–800) | The Baloo 2 Project Authors (Ek Type) |
| `bangers-latin.woff2` | Bangers | Vernon Adams |
| `lalezar-arabic.woff2` | Lalezar | The Lalezar Project Authors (Borna Izadpanah) |

Downloaded from fonts.googleapis.com on 2026-10-22. To refresh them, request the same families from the Google Fonts CSS API with a modern browser user agent and save the `arabic` and `latin` woff2 subsets under these names.
