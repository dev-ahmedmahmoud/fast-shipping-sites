# Cairo (type only)

One family for everything: [Cairo](https://github.com/Gue3bara/Cairo), a modern Arabic and Latin sans (variable weight, SIL OFL 1.1, license in `type-fonts/`). Headings in 800, bold text in 700, body in 400. Self-hosted, so nothing is fetched from another site.

The TantaSportsClubElections reference site (ashrafmoharamlist.com) uses it for all its text. Use it as the `type` part of a sample, for example `{ "palette": "royal-blue", "type": "cairo", "layout": "station", "motion": "station" }`.
